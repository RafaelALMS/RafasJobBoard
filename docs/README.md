## Capture tips

- Start the app with `npm run dev` and open http://localhost:5173.
- Upload a real resume first — empty profiles show no scores, which makes for a dull shot.
- Desktop viewport ≈ **1280×900**; optionally one mobile shot at **390×844**.
- Take each shot in both light and dark mode; keep files ≤ ~300 KB (compress with
  [squoosh.app](https://squoosh.app) or `pngquant`).
- PNG is fine for UI; hide any personal data (real resume details, email) before capturing.
